# Security policy

This draft repository has no deployable vault contracts, custody accounts, keys, or emergency controls.

Report vulnerabilities privately through **Security > Report a vulnerability** on this repository. Do not open a public issue or post exploit details.

Report rules or schemas that could misprice shares, omit custody, misallocate claims, accept false conformance, or break canonicalization, hashing, signatures, arithmetic, or settlement binding. Include the affected rule, a minimal reproducer, the expected result, and user impact.

Reports are accepted against current `main` and the latest tagged release. Implementations must identify their commit or release. Report deployed-vault incidents to the deployment's operator or security team.
